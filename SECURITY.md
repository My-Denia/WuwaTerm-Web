# Security reports

Do not post credentials, private endpoint details or exploit material in a
public issue. Use the [WuwaTerm security reporting policy](https://github.com/My-Denia/WuwaTerm/blob/main/SECURITY.md)
for coordinated reports spanning the Web and backend repositories.

The public beta is best-effort. A passing dependency audit or CI run is not a
claim that production has adopted that source revision.
